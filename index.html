Janus IA

In daily use · private

A personal multi-agent operating system. LLM agents coordinated over MCP share one memory, pick up each other's work, and run every task as a verified loop — a written goal, acceptance criteria and a check that proves each one.

  • Three-layer brain: Markdown knowledge vault, pgvector semantic memory on Supabase, and a Neo4j graph.
  • Runs Claude Code and Codex as interchangeable engines; routes each request to a fast, standard or deep model tier.
  • React dashboard over a WebSocket bridge — windows, chats, project progress — and usable from a phone.
  • Loop protocol enforced by blocking hooks: 272 of 280 acceptance criteria met across 32 finished loops.

LOOL AI

Prototype · core try-on working

A virtual try-on widget for independent optical stores: customers see frames on their own face, live, from the store's website.

  • MediaPipe face mesh tracks the irises; frames are scaled from inter-pupillary distance and rotated with the head.
  • Smoothing keeps frames steady through blinks; high-DPI canvas rendering.
  • Embeds with one script tag. The camera runs in the browser and no image is ever stored.
